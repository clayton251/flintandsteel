Palworld

Flint and Steel Palworld server

What this server is

Flint and Steel Palworld is the Palworld server on the Flint and Steel Network. The network is a veteran-run Minecraft and game server network. The card says catch, build, and explore together. It is PvE, it has no password, and Steam, Xbox, PS5, and Mac can join.

The platform line is PvE, crossplay, and 20 players. The chip says Open. This is a community server, not a Minecraft world and not the Valheim join code.

How to join

The direct address is palworld.flintandsteelnetwork.com:49096. Join Multiplayer Game, open Community Servers, and search for Flint and Steel. Or connect directly with the address. The home page also says you can paste the address from the Palworld card into the connect box at the bottom.

There is no password. You do not use the All the Mods 10 whitelist or the Valheim code 308346. The home page checks Palworld live with the other non-Minecraft servers. The public status page is https://status.flintandsteelnetwork.com with no extra path.

The home page does not publish a Palworld vote link. Vote buttons there are for All the Mods 10, Vanilla Survival, and Create: Above and Beyond.

palworld.flintandsteelnetwork.com:49096

On this network

Counter-Strike 2 is casual and deathmatch for 20 players and uses a console connect command. 7 Days to Die is PvE co-op for 16 players and is listed in that game's server browser. Palworld stays in Community Servers, or on the direct address above.

Donations are completely optional. They help cover hosting, power, backups, and upkeep for a small veteran-run network. A donation includes no in-game perks, ranks, or advantages of any kind.

House rules

Play like someone else is building next to you. These are the house rules published for the Flint and Steel Network, and they apply on this server too.

  1. Be respectful. Harassment, slurs, and personal attacks are not welcome.
  2. No griefing and no stealing.
  3. No cheats, hacked clients, or x-ray.
  4. No lag machines or anything built to drag the server down.
  5. Keep chat friendly.
  6. Listen to staff.

Ranks

The home page publishes the network ranks. Member is granted on Discord verify. Veteran is automatic after 50 hours played. VIP is hand-picked by staff. Moderators are staff who help keep chat and the worlds fair. Admin runs the network.

Read the ranks on the home page.

Questions

How do I find the Palworld server?

Join Multiplayer Game, open Community Servers, and search for Flint and Steel. Or connect directly with palworld.flintandsteelnetwork.com:49096.

Is there a password?

No. The server is PvE with no password.

Who can join?

Steam, Xbox, PS5, and Mac can join. The server is crossplay for up to 20 players.

Is this a Minecraft server?

No. Palworld is its own game on the network. The Minecraft servers are All the Mods 10, Vanilla Survival, and Create: Above and Beyond.
