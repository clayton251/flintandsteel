Valheim

Valheim crossplay server

What this server is

Valheim, short code VALHEIM, is the crossplay world on the Flint and Steel Network. The network is a veteran-run Minecraft and game server network. The card says Steam and Xbox players use the same join code. The platform line is Crossplay, and the chip says Join code.

This is not a Minecraft address. All the Mods 10, Vanilla Survival, and Create: Above and Beyond are the Minecraft servers. Valheim uses a join code instead of a host name.

How to join

The join code is 308346. Open Valheim, choose Join Game, and enter this code. Steam and Xbox can join the same world. Enter the code from the Valheim card, or copy it from this page.

There is no port to add and no Minecraft whitelist step. The home page checks Valheim live along with the other non-Minecraft servers. The public status page is https://status.flintandsteelnetwork.com with no extra path.

The home page lists vote buttons for the Minecraft servers only. It does not publish a Valheim vote link. Do not reuse an All the Mods 10 or Vanilla Survival vote button for this world.

On this network

Palworld, Counter-Strike 2, and 7 Days to Die are the other non-Minecraft servers, and each has its own join method. Palworld is in the community server list. Counter-Strike 2 uses a console connect command. 7 Days to Die is in the in-game server browser. Valheim stays on the join code.

Donations are completely optional. They help cover hosting, power, backups, and upkeep for a small veteran-run network. A donation includes no in-game perks, ranks, or advantages of any kind.

House rules

Play like someone else is building next to you. These are the house rules published for the Flint and Steel Network, and they apply on this server too.

  1. Be respectful. Harassment, slurs, and personal attacks are not welcome.
  2. No griefing and no stealing.
  3. No cheats, hacked clients, or x-ray.
  4. No lag machines or anything built to drag the server down.
  5. Keep chat friendly.
  6. Listen to staff.

Ranks

The home page publishes the network ranks. Member is granted on Discord verify. Veteran is automatic after 50 hours played. VIP is hand-picked by staff. Moderators are staff who help keep chat and the worlds fair. Admin runs the network.

Read the ranks on the home page.

Questions

How do I join the Valheim server?

Open Valheim, choose Join Game, and enter the code 308346.

Can Xbox players join?

Yes. Steam and Xbox players use the same join code and can join the same world.

Is there a Minecraft-style address?

No. Valheim uses the join code 308346. The Minecraft servers use their own public host names.

Do I need a whitelist?

The Valheim card does not list a Discord whitelist. Join with the code. Whitelist linking in #link-account is for All the Mods 10 and Create: Above and Beyond.
