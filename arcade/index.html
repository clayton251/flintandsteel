Strike a spark. Stay for the build.

A veteran-run corner of the Flint and Steel Network. This is not a live game server. The emulator runs entirely in your browser.

ROM files stay 100% in your browser. Choosing or dropping a file reads it here with URL.createObjectURL. Nothing is uploaded to Flint and Steel Network, and nothing is sent to anyone else.

Flint and Steel Network does not host or distribute commercial ROMs or BIOS files. The shelf below is free homebrew whose licenses allow redistribution. You are responsible for any file you load.

Drop your own ROM

The system is picked from the file extension. Change it when a file is a zip, a disc image, or a generic .bin.

Optional BIOS, kept on this device

PlayStation and Game Boy Advance can use a BIOS you already have. A PlayStation game works best as one .chd or .pbp file. The BIOS is read only in this browser.

Pick a homebrew game, or drop a ROM you have the rights to play.

Saves
In-game saves and save states stay in this browser’s local storage. The toolbar can download a save and load one back, and it can save and load states. Clearing site data removes them. Nothing is uploaded.
