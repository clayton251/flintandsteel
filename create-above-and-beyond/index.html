Create: Above and Beyond Minecraft server

What this server is

Create: Above and Beyond, short code CABAB, is a Minecraft server on the Flint and Steel Network. The network is a veteran-run Minecraft and game server network. The card calls this the 1.16.5 Create modpack, and it is whitelisted through Discord.

This is not All the Mods 10. All the Mods 10 is the NeoForge 1.21.1 modded tech server at atm10.flintandsteelnetwork.com. Create: Above and Beyond stays on Minecraft 1.16.5 and uses its own host.

How to join

The public join address is cabab.flintandsteelnetwork.com. Like the other Minecraft join addresses on this network, it is a public name with no port. Add that host in the Create: Above and Beyond instance and connect.

Modded servers need the matching CurseForge pack and a Discord whitelist. Install CurseForge and the Create: Above and Beyond modpack. Launch that pack, add cabab.flintandsteelnetwork.com, and connect. Then join the Flint and Steel Discord and open #link-account. Verify and link your Minecraft account there to get whitelisted.

The home page does not list a live map button on this card. All the Mods 10 publishes atm10map.flintandsteelnetwork.com, and Vanilla Survival publishes map.flintandsteelnetwork.com. Use those maps only for those worlds. The public status page is https://status.flintandsteelnetwork.com with no extra path, and the home page checks this Minecraft server live.

On this network

Vanilla Survival is the open Paper server with a castle spawn and no whitelist. Its address is vanilla.flintandsteelnetwork.com. Create: Above and Beyond keeps the Discord whitelist, the same kind of whitelist All the Mods 10 uses.

Every vote helps keep the servers online. Most lists ask for your Minecraft name. The links below are the CurseForge pack and the vote pages published for Create: Above and Beyond.

House rules

Play like someone else is building next to you. These are the house rules published for the Flint and Steel Network, and they apply on this server too.

  1. Be respectful. Harassment, slurs, and personal attacks are not welcome.
  2. No griefing and no stealing.
  3. No cheats, hacked clients, or x-ray.
  4. No lag machines or anything built to drag the server down.
  5. Keep chat friendly.
  6. Listen to staff.

Ranks

The home page publishes five network ranks. Member is granted on Discord verify. Veteran is automatic after 50 hours played: 400 claimed chunks and /fly. VIP is hand-picked by staff. Moderators are staff who help keep chat and the worlds fair. Admin runs the network.

Read the ranks on the home page.

Questions

What version is Create: Above and Beyond?

It is the 1.16.5 Create modpack. Install that pack from CurseForge, not the All the Mods 10 pack.

Is Create: Above and Beyond whitelisted?

Yes. It is whitelisted through Discord. Open #link-account, then verify and link your Minecraft account.

What address do I add?

cabab.flintandsteelnetwork.com. Do not add a port. That public name is the join address.

Which modpack do I launch?

Create: Above and Beyond on CurseForge. Launch that pack, add the address, and connect.
