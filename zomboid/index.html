Project Zomboid

Flint and Steel Network | Project Zomboid

What this server is

Project Zomboid on the Flint and Steel Network is named Flint and Steel Network | Project Zomboid. The network is a veteran-run Minecraft and game server network. This server is Build 42 on the public branch. It is vanilla PvE survival in Muldraugh, KY.

It has 32 slots. There is no password. It is VAC secure. The chip on the home card says Open.

Nightly backups and empty-only automatic restarts and updates run around 6:15 AM ET. A restart or update waits until nobody is online.

How to join

Direct connect, or add the server to Favorites, at zomboid.flintandsteelnetwork.com:57257. Or find Flint and Steel Network | Project Zomboid in the in-game or Steam server browser.

You do not install a mod pack, and you do not enter a password. The only Project Zomboid address published on the site is zomboid.flintandsteelnetwork.com:57257. The home page checks Project Zomboid live from the network status feed. The public status page is https://status.flintandsteelnetwork.com with no extra path. The home page does not publish a Project Zomboid vote link. Vote buttons there are for the Minecraft servers.

zomboid.flintandsteelnetwork.com:57257

On this network

Terraria is Classic on a large world and joins by IP. Garry's Mod is sandbox on gm_construct and joins from the console or Steam Favorites. DayZ is vanilla PvP on Chernarus. Rust stays on the Community tab or the connect command. Project Zomboid stays on the direct address or the server browser listing.

Donations are completely optional. They help cover hosting, power, backups, and upkeep for a small veteran-run network. A donation includes no in-game perks, ranks, or advantages of any kind.

House rules

Play like someone else is building next to you. These are the house rules published for the Flint and Steel Network, and they apply on this server too.

  1. Be respectful. Harassment, slurs, and personal attacks are not welcome.
  2. No griefing and no stealing.
  3. No cheats, hacked clients, or x-ray.
  4. No lag machines or anything built to drag the server down.
  5. Keep chat friendly.
  6. Listen to staff.

Ranks

The home page publishes the network ranks. Member is granted on Discord verify. Veteran is automatic after 50 hours played. VIP is hand-picked by staff. Moderators are staff who help keep chat and the worlds fair. Admin runs the network.

Read the ranks on the home page.
