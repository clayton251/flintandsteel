Terraria

Flint and Steel Network | Terraria

What this server is

Terraria on the Flint and Steel Network is named Flint and Steel Network | Terraria. The network is a veteran-run Minecraft and game server network. This server runs Terraria 1.4.5.8 on TShock. The difficulty is Classic. The world is large and named FlintAndSteel.

It has 16 slots. There is no password. The chip on the home card says Open.

Nightly backups and empty-only automatic restarts and updates run around 6:10 AM ET. A restart or update waits until nobody is online.

How to join

Open Terraria, choose Multiplayer, then Join via IP. Enter terraria.flintandsteelnetwork.com. The port is 4379. There is no password.

You do not install a mod pack, and you do not enter a password. The only Terraria address published on the site is terraria.flintandsteelnetwork.com:4379. The home page checks Terraria live from the network status feed. The public status page is https://status.flintandsteelnetwork.com with no extra path. The home page does not publish a Terraria vote link. Vote buttons there are for the Minecraft servers.

terraria.flintandsteelnetwork.com:4379

On this network

Project Zomboid is vanilla PvE in Muldraugh and is listed in that game's server browser. Garry's Mod is sandbox on gm_construct and joins from the console or Steam Favorites. DayZ is vanilla PvP on Chernarus. Rust stays on the Community tab or the connect command. Terraria stays on Join via IP.

Donations are completely optional. They help cover hosting, power, backups, and upkeep for a small veteran-run network. A donation includes no in-game perks, ranks, or advantages of any kind.

House rules

Play like someone else is building next to you. These are the house rules published for the Flint and Steel Network, and they apply on this server too.

  1. Be respectful. Harassment, slurs, and personal attacks are not welcome.
  2. No griefing and no stealing.
  3. No cheats, hacked clients, or x-ray.
  4. No lag machines or anything built to drag the server down.
  5. Keep chat friendly.
  6. Listen to staff.

Ranks

The home page publishes the network ranks. Member is granted on Discord verify. Veteran is automatic after 50 hours played. VIP is hand-picked by staff. Moderators are staff who help keep chat and the worlds fair. Admin runs the network.

Read the ranks on the home page.
