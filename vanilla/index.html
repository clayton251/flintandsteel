Vanilla

Vanilla Survival Minecraft server

What this server is

Vanilla Survival, short code VANILLA, is the open Minecraft world on the Flint and Steel Network. The network is a veteran-run Minecraft and game server network. The server runs Paper. The card describes a castle spawn and says the world is open to anyone: add the address and play.

The chip on the card says Open. There is no whitelist. That is the difference from All the Mods 10 and Create: Above and Beyond, which are both whitelisted through Discord.

How to join

The public join address is vanilla.flintandsteelnetwork.com. Minecraft join addresses on this network are the public names, and this one does not include a port. Open Minecraft Java Edition, choose Multiplayer, add a server, and paste the Vanilla address. Then join. There is no whitelist.

You do not need CurseForge for this world, and you do not need to open #link-account before you play. Those steps are for the modded servers. All the Mods 10 uses atm10.flintandsteelnetwork.com on NeoForge 1.21.1. Create: Above and Beyond uses cabab.flintandsteelnetwork.com for the 1.16.5 Create modpack.

A live map for Vanilla Survival is published at map.flintandsteelnetwork.com. The All the Mods 10 map is a different host, atm10map.flintandsteelnetwork.com. The public status page is https://status.flintandsteelnetwork.com with no extra path. The home page checks this Minecraft server live.

On this network

Every vote helps keep the servers online. Most lists ask for your Minecraft name. The links below are the vote pages published for Vanilla Survival. Donations are completely optional and include no in-game perks, ranks, or advantages of any kind.

House rules

Play like someone else is building next to you. These are the house rules published for the Flint and Steel Network, and they apply on this server too.

  1. Be respectful. Harassment, slurs, and personal attacks are not welcome.
  2. No griefing and no stealing.
  3. No cheats, hacked clients, or x-ray.
  4. No lag machines or anything built to drag the server down.
  5. Keep chat friendly.
  6. Listen to staff.

Ranks

The home page publishes five network ranks. Member is granted on Discord verify. Veteran is automatic after 50 hours played: 400 claimed chunks and /fly. VIP is hand-picked by staff. Moderators are staff who help keep chat and the worlds fair. Admin runs the network.

Read the ranks on the home page.

Questions

What version of Minecraft is Vanilla Survival?

The server card lists it as Paper. Open Minecraft Java Edition, add the address, and join. There is no modpack to install.

Is there a whitelist?

No. Vanilla Survival is open to anyone. Add the address and play.

What address do I add?

vanilla.flintandsteelnetwork.com. Do not add a port. That public name is the join address.

Is there a live map?

Yes. The Vanilla live map is at map.flintandsteelnetwork.com.
