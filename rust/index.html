Rust

Flint and Steel Network | Vanilla PvP

What this server is

Rust on the Flint and Steel Network is named Flint and Steel Network | Vanilla PvP. The network is a veteran-run Minecraft and game server network. This server is vanilla PvP. There are no mods, no kits, and no pay-to-win. Raiding is allowed everywhere.

It has 50 slots. There is no password. Easy Anti-Cheat is on. The chip on the home card says Open.

The map is a Procedural Map, size 3500. The forced wipe is monthly, on the first Thursday, after Facepunch's update, in the afternoon US Eastern. The map and bases wipe. Blueprints are kept unless Facepunch forces a blueprint wipe. The Rust+ companion app works.

How to join

Open Rust and search for Flint and Steel in the Community tab of the server browser. The listing name is Flint and Steel Network | Vanilla PvP. Or press F1 and run the connect command on this page.

You do not install a mod pack, and you do not enter a password. Easy Anti-Cheat is already part of joining this server. The home page checks Rust live from the network status feed. The public status page is https://status.flintandsteelnetwork.com with no extra path. The home page does not publish a Rust vote link. Vote buttons there are for the Minecraft servers.

client.connect rust.flintandsteelnetwork.com:4311

On this network

Counter-Strike 2 is casual and deathmatch and is found in Steam's game server list. 7 Days to Die is PvE co-op and is listed in that game's server browser. Palworld is a PvE community server. Valheim uses a join code. Rust stays on the Community tab or the connect command.

Donations are completely optional. They help cover hosting, power, backups, and upkeep for a small veteran-run network. A donation includes no in-game perks, ranks, or advantages of any kind.

House rules

Play like someone else is building next to you. These are the house rules published for the Flint and Steel Network, and they apply on this server too.

  1. Be respectful. Harassment, slurs, and personal attacks are not welcome.
  2. No griefing and no stealing.
  3. No cheats, hacked clients, or x-ray.
  4. No lag machines or anything built to drag the server down.
  5. Keep chat friendly.
  6. Listen to staff.

Ranks

The home page publishes the network ranks. Member is granted on Discord verify. Veteran is automatic after 50 hours played. VIP is hand-picked by staff. Moderators are staff who help keep chat and the worlds fair. Admin runs the network.

Read the ranks on the home page.
