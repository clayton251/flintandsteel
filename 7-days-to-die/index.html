7DTD

7 Days to Die PvE server

What this server is

7 Days to Die, short code 7DTD, is the 7 Days to Die server on the Flint and Steel Network. The network is a veteran-run Minecraft and game server network. The platform line is PvE co-op for 16 players. The chip says Open.

The world is vanilla V 3.4 on the V1.x line. The map is Navezgane. Play is PvE with no player killing, and a blood moon horde comes every 14 days. Easy Anti-Cheat is on. There is no password.

The in-game listing name is Flint and Steel Network | 7 Days to Die PvE. Search the in-game server browser for Flint and Steel.

How to join

Open 7 Days to Die. Search the in-game server browser for Flint and Steel. The listing is Flint and Steel Network | 7 Days to Die PvE. Or choose Connect to IP and paste the address. The port is 28246.

The address is 7dtd.flintandsteelnetwork.com:28246. That hostname and port are the only 7 Days to Die address on the site. You do not use the Valheim code, the Palworld port, or a Minecraft host for this game.

The home page checks this server live from the network status feed. The public status page is https://status.flintandsteelnetwork.com with no extra path. The home page does not publish a 7 Days to Die vote link. Vote buttons there are for the Minecraft servers.

7dtd.flintandsteelnetwork.com:28246

On this network

Counter-Strike 2 is casual and deathmatch and is found in Steam's game server list. Palworld is a PvE community server for up to 20 players with no password. Valheim is crossplay with join code 308346. 7 Days to Die stays on the listing name and the address above.

Donations are completely optional. They help cover hosting, power, backups, and upkeep for a small veteran-run network. A donation includes no in-game perks, ranks, or advantages of any kind.

House rules

Play like someone else is building next to you. These are the house rules published for the Flint and Steel Network, and they apply on this server too.

  1. Be respectful. Harassment, slurs, and personal attacks are not welcome.
  2. No griefing and no stealing.
  3. No cheats, hacked clients, or x-ray.
  4. No lag machines or anything built to drag the server down.
  5. Keep chat friendly.
  6. Listen to staff.

Ranks

The home page publishes the network ranks. Member is granted on Discord verify. Veteran is automatic after 50 hours played. VIP is hand-picked by staff. Moderators are staff who help keep chat and the worlds fair. Admin runs the network.

Read the ranks on the home page.
